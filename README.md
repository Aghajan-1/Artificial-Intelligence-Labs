## How to Run

1. Open [Google Colab](https://colab.research.google.com/) or install Python 3 on your computer.
2. Create a new notebook or Python file for the selected lab.
3. Copy the code from that lab's Markdown file into code cells or a `.py` file.
4. Run the code and compare the result with the sample output.
5. For Lab 4, Matplotlib is required for plotting. Install it with `pip install matplotlib` if it is not already available.
